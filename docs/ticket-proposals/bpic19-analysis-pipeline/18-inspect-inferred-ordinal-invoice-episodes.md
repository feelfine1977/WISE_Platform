# 18: Inspect inferred ordinal invoice episodes

Status: **proposed — owner seam/breakdown review pending; not yet a published ready-for-agent issue**.

## What to build

The analyst applies one reviewed ordinal episode policy, inspects its matched/unmatched events and intervals, and returns to the complete original item.

## Acceptance criteria

- [ ] V1 pairs kth occurrences under an explicit ordering/tie policy; close-on-clearing is a separately activated extension and is not silently equivalent.
- [ ] Derived episode IDs, native business IDs, item IDs and raw event IDs stay distinct.
- [ ] Ambiguous, cancelled, missing, reversed and legitimate zero-duration outcomes have support/witness receipts; approximate intervals are not guessed.
- [ ] All item records remain retained; Inspect highlights an episode without cropping analytical case membership.
- [ ] Repeated-invoice literal fixtures and retained policy/episode identities pass the full seam and restart.
